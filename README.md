# Frontier Expedition

A caravan-crawler RPG inspired by **Darkest Dungeon 1 & 2**, set on an Oregon Trail-style
push west into a frontier that grows stranger the farther you go. Lead a pioneer company
out of the burned-out Fort Providence, fight outlaws, wolves, crows and mythic giants in
rank-based turn combat, manage Fatigue and supplies, camp under the stars, and raise new
settlements on the ground of every boss you beat. At the end of the trail waits the Great
Casino, whose chips are the frontier's currency.

Built in **Godot 4.7** with GDScript. Version is in `project.godot` (`config/version`, shown
bottom right in game).

## Playing

**From source (how the owner plays):** install Godot 4.7.2, clone this repo and run
`play.bat`. It pulls the latest `main`, imports new files and starts the game. Edit the
`GODOT=` line in it if Godot lives somewhere else. The game uses Godot's Vulkan renderer and
falls back to OpenGL if Vulkan can't start; `play_opengl.bat` forces OpenGL. Or open the folder in Godot and press F5.

**Windows build:** [`download/FrontierExpedition-windows.zip`](download/FrontierExpedition-windows.zip)
holds a single `.exe` (refreshed for major versions only, so it can lag behind `main`).
Windows may warn that the app is unrecognized (it isn't code-signed): *More info → Run
anyway*.

Saves and logs: `%APPDATA%\Godot\app_userdata\Frontier Expedition` (`save.json`,
`settings.json`, `logs\`).

Controls are mouse-first. **Esc** opens the menu and *How to Play*. **F11** toggles
fullscreen. **1-4** pick moves in combat. Right-click cancels targeting or closes a window.

## What's in it

- **10 classes**: Marshal, Mountain Mystic, Rail Driver, Gunslinger, Wrangler, Gambler,
  Prospector, Bayou Poisoner, Frontier Doctor and Preacher, with 6 to 8 moves each. A hero
  starts knowing 4 and learns the rest at the Drill Hall; 4 are equipped at a time.
  Three rolled color outfits per class.
- **Four-rank combat** with shown hit and crit chances, bleed, poison, stun, marks, guard,
  taunt, knockback and pulls, summons, Death's Door and permadeath.
- **Fatigue**, the stress system: Breaking Points (Homesick, Reckless, Paranoid...) or
  Second Winds (Steadfast, Inspired, Grit...).
- **12 survival skills** (Cook, Hunter, Scout, Wheelwright, Storyteller...) used at camp and
  on the trail, ranking up with use.
- **37 enemies**, **40 quirks**, **22 trinkets**, **36 trail events**, **21 curios**, 9
  supply items (food, medicine, lamp oil, curio keys, wagon parts).
- **Expeditions** on a branching trail map with scouting, fights, elites, events, curios,
  camps, lamplit caves, trading posts and homesteads, ending at a boss.
- **Regions:** the Old Mill Road (tutorial), the Tallgrass Sea (Silas Crane and his crows),
  the Red Canyons and the Thunder Peaks. Side adventures from Fort Providence (Dry Gulch
  Mine, The Crow's Nest) and weekly **Saloon rumors** (Mad Dog's Hideout and six more
  quest templates). Testing currently focuses on Fort Providence and the Tallgrass Sea.
- **Settlements** that grow Outpost → Town → City, with 9 buildings (Saloon, Chapel,
  Doctor, Smithy, Drill Hall, General Store, Hiring Board, Stage Line, Boot Hill).

Art: characters, the map, the town and the wood-and-rope UI are drawn in code; icons and
some backdrops are painted by the owner (ComfyUI) with the code drawing as fallback. Sound:
generated by `tools/gen_audio.py` plus CC0 recordings (`assets/audio/CREDITS.md`).

## For developers and agents

Start with **[`CLAUDE.md`](CLAUDE.md)** (working rules and checks) and
**[`docs/README.md`](docs/README.md)** (what each doc covers). The short version:

| Path | What |
|---|---|
| `data/*.json` | All content and balance numbers |
| `scripts/core/` | Game rules, node-free: combat engine, company, expedition, heroes, map |
| `scripts/screens/` | One script per screen, built in code |
| `scripts/visual/`, `scripts/ui/` | Code-drawn art; theme and widgets |
| `tests/`, `tools/` | Headless tests and simulators; checks, screenshots, audio and art tools |
| `assets/`, `art-src/` | Game-ready art and audio; the owner's original art |

```bash
tools/check.sh                                                  # compile every script
godot --headless --path . res://tests/test_runner.tscn          # tests (~6700 checks)
godot --headless --path . res://tests/test_runner.tscn -- balance=40 weeks=6   # balance report
tools/shot.sh combat /tmp/combat.png                            # screenshot (xvfb)
```

Releases: pushing a `v*` tag runs `.github/workflows/build.yml` (tests, Windows export, a
GitHub release).
