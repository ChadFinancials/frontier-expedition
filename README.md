# Frontier Expedition

A caravan-crawler RPG inspired by **Darkest Dungeon 1 & 2**, set on an Oregon Trail-style
push west into a frontier that grows stranger the farther you go. Lead a pioneer company
out of Fort Providence, fight outlaws, wolves and mythic giants in rank-based turn combat,
manage Fatigue and supplies, camp under the stars, and raise new settlements on the
ground of every boss you beat.

Built in **Godot 4.7** with GDScript. All art is drawn in code (paper-cutout style), and
all sound and music is generated by `tools/gen_audio.py`.

## Playing

**Windows:** download [`download/FrontierExpedition-windows.zip`](download/FrontierExpedition-windows.zip),
unzip it, and double-click `FrontierExpedition.exe`. It's one file with no install. Windows may warn
that the app is unrecognized (it isn't code-signed): click *More info → Run anyway*.
Saves go to `%APPDATA%\Godot\app_userdata\Frontier Expedition`.

**From source:** install [Godot 4.7](https://godotengine.org/download), open the
project folder, and press Play (F5).

Controls are all mouse. **Esc** opens the menu and *How to Play*. **F11** toggles
fullscreen. **1-4** pick skills in combat. Right-click cancels a target selection or closes
a window.

## What's in it

- **10 classes**, each with 6 combat skills (equip 4): Marshal, Mountain Man, Rail Driver,
  Gunslinger, Wrangler, Gambler, Prospector, Sharpshooter, Frontier Doctor, Preacher.
- **Four-rank combat** with explicit hit and crit chances, bleed, poison, stun, marks,
  guard, knockback and pulls, plus Death's Door and permadeath.
- **Fatigue**, the stress system: Breaking Points (Homesick, Reckless, Paranoid...) or
  Second Winds (Steadfast, Inspired, Grit...).
- **12 survival skills** (Cook, Hunter, Scout, Wheelwright, Storyteller...), which make two
  heroes of the same class play differently. Used at camp and on the trail, and they rank
  up with use.
- **40 quirks** (with compulsions), **21 keepsakes**, **30 trail events**, **21 curios**.
- **3 regions** (Tallgrass Sea, Red Canyons, Thunder Peaks), each with a boss: Silas
  Crane's gang, the Cyclops of Deadeye Mesa, and the Titan of the Pass.
- **Settlements** that grow Outpost → Town → City, with 9 building types (Saloon, Chapel,
  Doctor, Smithy, Drill Hall, General Store, Hiring Board, Stage Line, Boot Hill) and a
  stage line to move heroes between them.
- Side **caves** explored by lamplight, **camps**, **trading posts** and **homesteads**.

## Project layout

| Path | What |
|---|---|
| `data/*.json` | All content and balance numbers |
| `scripts/core/` | Game rules: combat engine, fatigue, heroes, company, expedition, map generation |
| `scripts/screens/` | One script per screen (settlement, trail, combat, camp, cave...) |
| `scripts/visual/` | Code-drawn art: figures, backdrops, town, map, wagon, curios |
| `scripts/ui/` | Theme and widgets |
| `tests/` | Headless test suite, balance simulator, UI autopilot |
| `tools/` | Audio generator, compile check, screenshot helper |
| `docs/` | Design brief, Darkest Dungeon research, GDD, content guide |

## Development

```bash
# Rules + data cross-checks (3000+ checks) and a simulated campaign
godot --headless --path . res://tests/test_runner.tscn

# Balance report: many simulated campaigns
godot --headless --path . res://tests/test_runner.tscn -- balance=40 weeks=6

# Play the real UI automatically (smoke test)
godot --headless --path . -- shot=autoplay expeditions=5

# Compile every script
tools/check.sh

# Screenshot a scene (needs xvfb): menu, settlement, embark, trail, combat, camp, cave, results, lineup
tools/shot.sh combat /tmp/combat.png

# Regenerate all audio
python3 tools/gen_audio.py

# Build the Windows .exe (needs Godot export templates)
godot --headless --path . --export-release "Windows Desktop" build/windows/FrontierExpedition.exe
```

Adding classes, skills, enemies, events and regions is covered in
[`docs/ADDING_CONTENT.md`](docs/ADDING_CONTENT.md).
