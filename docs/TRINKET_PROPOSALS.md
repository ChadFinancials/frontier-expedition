## How class trinkets are found
- They join the normal trinket pool at their rarity, so curios, elites, the trinket peddler and
  bosses can all turn them up.
- 🛠 A little weighting toward classes you actually have in the roster, so they don't feel
  wasted (for example, double weight for a class you own).
- A class trinket in the stash shows which class can wear it; only that class can equip it.

## Engine hooks the 🛠 rows need
- **Class restriction** on equipping (`"class"` field).
- **Per-move bonuses** (`"skill_mods": {move: {dmg_pct, acc, crit, effect_chance, rounds, amount,
  heal, knockback}}`): one hook covers the Warrant Book, Elk-Bone Charm, Golden Spike, Collar,
  Riata, Ether Bottle and River Water.
- **Conditions** `guarding` (Guarding or Taunting) and `poisoned`.
- **Stats** `heal_out_pct` (heals given), `stun_chance` (bonus to the user's stun chance),
  `poison_dot` (+N on poisons applied), `momentum_start`, `momentum_bonus`, and
  `card_pct` (Stacked Deck boon size).
